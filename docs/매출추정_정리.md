## 2. Breakdown — DART보다 한 단계 더 쪼개기

```
매출
├─ 컴포넌트
│   ├─ Capacitors(MLCC)      ← IR 분기 비중 89~92%
│   ├─ 전자소자               ← 나머지 8~10%
│   └─ 실리콘 커패시터 (신규)   ← LTA 공시 $1,035mn, 2027~28년
├─ 패키지솔루션
│   ├─ FCBGA                 ← 대신증권 추정 비중(1Q25 48% → 3Q26 63%)
│   └─ BGA
└─ 광학솔루션 (단일 라인)      ← 응용처를 나눌 근거 수치가 없음
```

쪼개는 기준은 두 가지다. 하나는 드라이버가 서로 다른가이고, 다른 하나는 숫자로 확인할 근거가 있는가다. 그래서 근거가 없는 광학의 스마트폰/전장 구분과 MLCC의 응용처 구분은 하지 않았다.

전 부문에 같은 분해 틀을 썼다: 매출 = Q(DART 생산량) × P(매출÷생산량을 달러로 환산) × 환율.

## 3. 라인별 추정 논리

### 컴포넌트 (2026E 6.99조 → 2027E 9.62조 → 2028E 10.81조)
- **Q(억개)**: 2023년 Capa는 12,568억개였는데 2025년 11,159억개로 줄었다. 고적층·고용량 제품 비중이 커지면서 개당 공정시간이 늘었기 때문이다. 같은 기간 가동률은 70%에서 93%로 올랐다. 따라서 성장을 끌고 가는 것은 개수가 아니라 믹스(P)다.
- **P(USD/천개)**: 2025년 $3.52 → 1H26 $3.67 → 2H26E $4.90. 3Q26 달러 매출은 전 분기보다 21% 늘었다.
- **4Q26E**: Q +5%, ASP +10% QoQ로 잡아 달러 매출 +15.5%, 원화 2.05조(QoQ +9%).
- **2027E**: Q +6%(필리핀 신공장), P +12%(2H26 평균 대비, 4Q26 연말 수준 대비로는 +7%). 여기에 실리콘 커패시터 LTA 0.69조를 더했다.
- **크로스체크**: 공시된 MLCC LTA($2.35bn)가 당사 2027E MLCC 매출의 38%를 덮는다. 회사는 「2027년 매출의 과반이 LTA」라고 했고, 나머지는 공시 기준에 못 미치는 소형 LTA로 본다.
  - 증권사 평균을 당사 Q·환율로 역산하면 P가 +29% 올라야 한다는 뜻이 된다. 이 가정 차이가 컨센과의 갭이다.

### 패키지솔루션 (3.43조 → 4.21조 → 5.31조)
- **Q(천㎡)**: 면적 Capa는 대면적·고다층화로 늘지 않는다. 2025년 810 → 1H26 연환산 732. 가동률은 2025년 70%에서 1H26 89%로 올랐다.
- **P(USD/㎡)**: 2025년 $2,861 → 1H26 $3,100 → 2H26E $4,042. 공시 ASP는 1H26 +18.7%, 원재료 CCL/PPG는 +17.4%다.
- **2027E**: 신규 공장 완공이 2028년 4~5월이라 Q는 +5%에 그치고, P는 +10%로 잡았다.
- **2028E**: 신규 Capa를 기존 Capa의 50%, 2028년 기여율을 35%로 놓으면 면적이 +20% 늘고, P는 +5%다.
- **FCBGA 비중**: 2026E 61% → 2027E 67% → 2028E 72%.

### 광학솔루션 (3.85조 → 3.52조 → 3.55조)
- 가동률이 66~70%로 Capa에 여유가 있어 매출은 수요가 정한다.
- P는 2023~2025년 +32% 올랐지만 2026년 들어 멈췄다.
- **2027E**: 메모리 가격 급등으로 스마트폰 수요가 둔화된다고 보고 Q −5%, P +3%(2026E 평균 대비)로 잡았다. 환율 효과까지 넣으면 원화 기준 −9%다.

### 공통 가정 — 환율
- 4Q26E~2028E 모두 1,340원으로 고정했다. 4Q26 QTD 평균이고, 11/10 현재 1,337원이다.
- 환율이 ±100원 움직이면 매출은 ±7.5% 바뀐다(REV 시트 민감도 표).
